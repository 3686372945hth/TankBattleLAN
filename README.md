# TankBattleLAN 局域网坦克大战

一款支持 **Windows + Android 双端** 的局域网双人对战坦克游戏，基于团结引擎（Tuanjie 1.10.4 / Unity 2022.3.62t16）开发，网络层使用 Mirror。同一路由器下即可开房对战，无需服务器。

---

## 项目简介

两名玩家在同一局域网内创建 / 加入房间进行实时对战。战场包含砖墙（可击毁）、钢墙（不可穿透）与两座基地，双方通过打空对方坦克血量或击毁对方基地决出胜负。

## 功能特性

- 局域网双人实时联机，帧同步状态走 Mirror SyncVar
- Windows 桌面端 + Android 移动端双端互通
- 玩家分色：玩家 1 蓝色、玩家 2 浅红色，白色炮管指示朝向
- 血量制：每台坦克 3 点血，中弹扣 1 点
- 双胜负条件：打空对方坦克，或击毁对方基地（打自己基地会判对方胜）
- 砖墙可击毁、钢墙不可穿透，砖墙生成时自动避开出生点与基地
- 完整对局闭环：胜利 / 失败 / 对手断开 三种结算，空格或点击屏幕返回主菜单
- 断线提示：房主中途退出时，客机弹出「房主已断开」
- 操作手感双端差异化：PC 逐帧转向，移动端摇杆直接对准

## 操作说明

### Windows 端

| 按键 | 功能 |
| --- | --- |
| W | 前进 |
| S | 后退 |
| A | 左转 |
| D | 右转 |
| 空格 | 发射炮弹（冷却 0.5 秒） |
| 空格 / 鼠标点击 | 结算界面返回主菜单 |

### Android 端

- 左下角虚拟摇杆：拖动控制坦克朝向并持续前进
- 右下角「射击」按钮：发射炮弹
- 松开摇杆：停止移动，保持当前朝向
- 结算界面：点击屏幕任意位置返回主菜单

## 玩法规格

| 项目 | 数值 |
| --- | --- |
| 坦克血量 | 3 |
| 单发伤害 | 1 |
| 射击冷却 | 0.5 秒 |
| 移动速度 | 5 单位/秒 |
| 出生点 | 玩家 1 在 (-4.5, 0)，玩家 2 在 (4.5, 0) |
| 基地位置 | x = ±6.5 |
| 砖墙 | 约 40 块，14×9 区域内随机，避让出生点 1.6、基地 1.8 |
| 联机端口 | 7777（UDP） |

## 局域网联机教程

1. 两台设备连接**同一路由器 / 同一 WiFi**。
2. **主机**：启动游戏 → 点「创建房间」→ 记下本机局域网 IP（如 `192.168.1.10`）。
3. **客机**：启动游戏 → 在输入框填写主机 IP → 点「加入房间」。
4. 双方进入战场，先打空对方 3 点血或击毁对方基地者获胜。
5. 结算界面按空格（PC）或点屏幕（双端）回到主菜单，可继续下一局。

> Windows 首次运行时系统会弹出防火墙提示，必须选择「允许访问」，否则客机无法连接。若误点了拒绝，可在「Windows  Defender 防火墙 ▸ 允许应用通过防火墙」里手动勾选，或放行 UDP 7777 端口。

> 客机连不上时，先确认两台设备能互相 ping 通，再检查主机是否处于「创建房间」界面（此时端口才处于监听状态）。

## 脚本职责

| 脚本 | 职责 |
| --- | --- |
| `CustomNetworkManager` | 网络管理：开房/加入、玩家生成与槽位分配、基地生成、断线回调 |
| `TankController` | 坦克移动、转向、射击，颜色与结算状态同步 |
| `TankHealth` | 血量初始化与受伤判定，血量归零触发结算 |
| `Bullet` | 子弹命中判定：砖墙、钢墙、坦克、基地四类目标 |
| `Base` | 基地归属（`ownerSlot`）与颜色表现 |
| `BrickSpawner` | 服务端随机生成砖墙，避让出生点、基地，砖块互不重叠 |
| `SteelWallSpawner` | 生成地图外围钢墙 |
| `GameManager` | 对局开始标记、胜负结算、结算面板、返回主菜单流程 |
| `MenuManager` | 主菜单、IP 输入、创建/加入房间 |
| `Joystick` | 移动端虚拟摇杆输入 |
| `TouchInputManager` | 移动端输入绑定与本地坦克关联 |
| `NetworkMessages` | 自定义网络消息定义（预留） |

## 本地运行

1. 克隆仓库
2. 用团结引擎打开项目根目录
3. 打开 `Assets/Scenes/Main.scene`，点运行
4. 编辑器内可直接「创建房间」并在另一台设备（或用打包出的 exe）加入

## 打包

**Windows**

1. 「文件 ▸ 生成设置」，平台选 Windows，确认场景列表只有 `Main.scene`
2. 点「生成」，输出到任意目录（如 `D:\Downloads\Tank\Windows`）

**Android**

1. 「文件 ▸ 生成设置」→ Android →「切换平台」
2. 确认已配置 JDK / SDK / NDK（团结 Hub 中安装）
3. 点「生成」得到 APK，安装后与 PC 端联机

> 修改脚本后必须重新打包客户端，旧包里的逻辑不会更新。客机出现「毫无反应」「不进结算」时，优先怀疑客机跑的是旧包。

## 常见问题

**客机点「加入房间」没反应**
先确认主机已经点了「创建房间」，再看 Windows 防火墙是否放行。

**客机进了战场但打不死人 / 不进结算**
客机大概率是旧构建，重新打包后再测。

**结算文字显示成方框**
字体图集缺字。`Assets/Fonts/ChineseFont SDF.asset` 需保持 Dynamic 图集模式，或用 TMP 的「Window ▸ TextMeshPro ▸ Font Asset Creator」补字。

**返回主菜单后无法再开局**
当前版本返回菜单时会停掉网络，再次开局需要重新点「创建房间 / 加入房间」。

## 已知限制

- 仅支持 2 人对战，无房间列表与匹配
- 无对局回放、无观战
- 依赖局域网，不支持公网直连（需要端口映射或虚拟局域网工具）
- 结算面板的按钮与「点击屏幕」共用同一返回逻辑
