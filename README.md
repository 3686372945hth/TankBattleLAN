\# TankBattleLAN 局域网坦克大战 v1.0

一款支持 Windows + 安卓双端的局域网双人对战坦克游戏。



\## 功能特性

\- 双人局域网实时联机对战

\- PC 端经典 WASD 操作 + 安卓端摇杆方向跟随操作

\- 刚体物理碰撞，砖墙、钢墙阻挡正常

\- 玩家分色标识：玩家1蓝色、玩家2红色

\- 白色炮管朝向指示，直观分辨射击方向

\- 双端手感分离：PC 经典平滑旋转、安卓瞬间对准方向



\## 操作说明

\### Windows 端（经典坦克模式）

\- `W` / `S`：坦克前进 / 后退

\- `A` / `D`：坦克左转 / 右转

\- `空格`：发射炮弹



\### 安卓端（摇杆瞬间转向模式）

\- 摇杆向任意方向拖动，坦克炮管立刻对准对应方向并前进

\- 松开摇杆坦克停下，保持最后朝向

\- 点击右下角「射击」按钮发射炮弹



\## 联机方法

1\.  两台设备连接同一个局域网（同一路由器/WiFi）

2\.  主机创建房间，查看本机 IP 地址

3\.  客机输入主机 IP 地址，加入房间

4\.  双方准备完成后开始对战
