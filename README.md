# TankBattleLAN 局域网坦克大战

团结引擎（2022.3.62t16 / Tuanjie 1.10.4）+ Mirror 的 2D 双人局域网坦克对战，同一路由器即可开房，无需服务器。

## 玩法

- 双方各 3 点血，打空对方坦克或击毁对方基地获胜；打自己基地判对方胜。
- 砖墙可击毁，钢墙不可破坏；地图 48×28，内含 40 块随机钢墙、180 块砖墙。
- 开局 3-2-1 倒数后解锁操作；命中有分目标的爆炸特效与音效，阵亡坦克变灰。
- 相机始终跟随本地玩家，在地图边界内平滑移动。

## 操作

- PC：W/S 前后，A/D 转向，空格开火；结算时空格或点击返回菜单。
- 手机：左摇杆控制朝向并前进，右下按钮开火；结算点屏幕返回。

## 联机

1. 两台设备连同一 WiFi。
2. 主机点「创建房间」，记下本机局域网 IP。
3. 客机填主机 IP，点「加入房间」。

> 首次运行需在防火墙弹窗允许访问 UDP 7777；同机双开只能一个建房、一个加入。

## 工程

- 脚本在 `Assets/Scripts`，场景 `Assets/Scenes/Main.scene`，网络层 Mirror。
- 改完脚本或场景必须重新打包客户端，旧包不会更新。
