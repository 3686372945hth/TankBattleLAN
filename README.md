# ankBattleLAN 局域网坦克大战 v1.0

一款支持 **Windows + 安卓双端** 的局域网双人对战坦克游戏，基于团结引擎开发，支持实时联机、物理碰撞、双端差异化操作手感。

---

## 🎮 项目介绍

本项目为局域网双人对抗类坦克游戏，两名玩家在同一路由器网络环境下即可创建房间、加入房间进行实时对战。游戏包含砖墙、钢墙等地形元素，炮弹具备物理碰撞与反弹机制，双方通过击毁对方坦克获得胜利。

## ✨ 功能特性

- ✅ 局域网双人实时联机对战，低延迟同步
- ✅ 双端支持：Windows 桌面端 + 安卓移动端
- ✅ 玩家视觉区分：玩家 1 蓝色坦克、玩家 2 红色坦克
- ✅ 白色炮管朝向指示，清晰分辨射击方向
- ✅ 刚体物理碰撞：砖墙可击毁、钢墙不可穿透
- ✅ 双端操作手感差异化：
  - PC 端：经典 WASD 逐帧转向，还原传统坦克操作
  - 安卓端：摇杆方向瞬间对准，移动端跟手度更高

## 🎯 操作说明

### Windows 端（经典操作模式）

表格

| 按键 | 功能 |
| --- | --- |
| W | 坦克前进 |
| S | 坦克后退 |
| A | 坦克左转 |
| D | 坦克右转 |
| 空格 | 发射炮弹 |

### 安卓端（方向跟随模式）

- 左侧虚拟摇杆：拖动方向控制坦克朝向与移动
- 右下角射击按钮：点击发射炮弹
- 松开摇杆：坦克停止移动，保持当前朝向

## 🌐 局域网联机教程

### 准备工作

1. 两台设备连接 **同一个局域网**（同一路由器 / 同一 WiFi）。
2. 确保 Windows 防火墙允许游戏访问网络。

### 联机步骤

1. **主机（创建房间）**
   - 进入游戏点击「创建房间」
   - 查看本机局域网 IP 地址，告知客机玩家
2. **客机（加入房间）**
   - 进入游戏点击「加入房间」
   - 输入主机的局域网 IP 地址
   - 点击连接，等待主机开始
3. 双方准备完成后，即可开始对战。

## 🛠️ 环境与运行

### 开发环境

- 开发引擎：团结引擎
- 脚本语言：C#
- 网络框架：Mirror

### 运行要求

- **Windows 端**：Windows 10 及以上
- **安卓端**：Android 7.0 及以上

### 本地运行

1. 克隆仓库到本地
2. 用团结引擎打开项目根目录
3. 打开 `Main` 场景，点击运行即可
